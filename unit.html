Unit Converter

A quick unit converter for everyday measurements: convert miles to kilometers, pounds to kilograms, Fahrenheit to Celsius and more.

How to use this tool

Choose a measurement category, enter a number and select the source and target units. The result updates instantly. For linear measurements, we convert the source value into a shared base unit before calculating the target value. Temperature conversions use separate offset formulas. US cups and gallons follow US customary definitions.

Important note

This tool provides general estimates. Check the result before using it for important decisions.

Your entries are processed on your device; calculator inputs are not sent to a server.
