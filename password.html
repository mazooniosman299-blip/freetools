Secure Password Generator

Create random passwords using cryptographic browser randomness, with length and character controls. No data is sent to any server.

Include characters

How to use this tool

Select 8–128 characters and include letters, digits and symbols. The generator uses crypto.getRandomValues for unpredictable output and includes at least one character from each selected category.

Privacy & limitations

Files and inputs are processed in your browser. The tool does not send your content to our servers. Review outputs before important use.
