Create QR Codes That Scan Reliably

Learn how to make a readable QR code for a website, menu, contact card or poster using clear links, correct margins, print dimensions and testing.

Start with a working link

For a website destination, copy the full address, including https://. If a QR code is printed with an incorrect URL, its destination cannot be corrected inside the printed image. Open and test the address before you generate the QR code.

Prefer short content

QR symbols encode your actual text, not a magical shortcut. Long addresses and paragraphs contain more data and can lead to denser grids of squares. Short, simple content is generally easier to scan, particularly when the code is printed small.

Protect the white border

Keep an undisturbed white area around all four sides, also called the quiet zone. Surrounding photographs, borders or nearby printed text can interfere with detection. Use a dark pattern on a light background for a reliable contrast.

Choose a suitable size

A code on a business card and a code on a wall poster need different physical sizes. Export a sufficiently large PNG and scale the print according to scanning distance. Do not assume one minimum size fits every link, camera or lighting condition.

Understand what static means

Our generator creates static QR codes: the data is embedded in the symbol and does not need a paid redirection service. A new link requires a newly generated code. An outside service selling dynamic QR codes instead usually hosts a redirect, so its ongoing availability matters.

Test before sharing

Scan the finished code on two different phones if possible, using the actual final print or screen. Check that it opens the intended address and does not contain unexpected spaces. Never encode passwords, authentication codes or private tokens: people who see the QR can recover its content.
