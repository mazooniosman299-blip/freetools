Strong Passwords: Length, Uniqueness and Safe Storage

Learn how to create unique random passwords, avoid password reuse, store credentials safely and add extra sign-in protection.

Long and unpredictable beats familiar

A name, phone number or birthday is guessable, even when you insert symbols. Choose a sufficiently long password generated with a secure random source. Avoid obvious sequences and song titles: attackers can test many common choices.

Every account needs its own password

Using the same password for email, shopping and social media means that a single password leak can expose unrelated accounts. Generate and save a distinct password for each service, especially your primary email and banking accounts.

What this generator does

Our password generator uses the browser's cryptographic random number API when available and lets you select character categories and a length from 8 to 128. It creates the result locally in the page and does not upload or keep a server-side copy.

Use a password manager

Random passwords are difficult to remember, and that is expected. A reputable password manager can store unique passwords, while you remember one strong master password. Keep recovery information secure and avoid storing an unprotected list on shared devices.

Add another layer

When available, activate passkeys or multifactor authentication. A stolen password is then less likely to be enough for access. Never give another person a one-time code, and be suspicious of websites that imitate the sign-in page of a service you use.

Be careful when sharing

Don't share passwords in QR codes, screenshots or messaging apps. Once you copy a generated password, other software may be able to read your clipboard. Paste it only into the intended account setup page and clear your clipboard when finished.
